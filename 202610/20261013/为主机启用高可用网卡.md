# 为主机启用高可用网卡

## Context

为主机启用高可用网卡，为实现网络高可用，可使用bond技术将多个物理网卡绑定为一个虚拟网卡，使用active-backup模式实现网络高可用

---

## Key Takeaway

- 创建一个绑定组：`nmcli connection add con-name bond1 ifname bond1 type bond mode active-backup`
- 将物理网卡加入绑定组：`nmcli connection add con-name bond1-ens19 ifname ens19 type bond-slave master bond1`
- 将物理网卡加入绑定组：`nmcli connection add con-name bond1-ens20 ifname ens20 type bond-slave master bond`
- 为绑定组设置IP信息：`nmcli connection modify bond1 ipv4.method manual ipv4.addresses 192.168.1.1/24 ipv4.gateway 192.168.1.254 ipv4.dns 223.5.5.5`

---

## Pratice

- nmcli是以device与connection视角进行操作网络的
- connection以连接为对象进行操作，一个网卡设备可以有多个配置
- device以设备对象进行操作
