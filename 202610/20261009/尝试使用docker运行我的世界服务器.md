# 尝试使用docker运行我的世界服务器

## Context

尝试使用docker运行我的世界服务器，使用容器化方式运行可以更方便的隔离环境

---

## Key Takeaway

- docker volume create <volume-nmae> 创建数据卷
- docker compose里的一些资源限制：如mem_limit、cpus、memswap_limit限制内存与cpu
- docker compose引用外部数据卷
- docker compose分配虚拟终端与开启标准输入：stdin_open、tty
- 创建基础的Dockerfile构建文件与.dockerignore忽略文件
