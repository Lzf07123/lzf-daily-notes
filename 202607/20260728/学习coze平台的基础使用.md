## Pratice

```bash
生成式大模型与智能体最大的区别在于智能体有自主决策能力
# System Prompt普遍使用markdown格式进行表示
ROLE #约束智能体的角色，聚焦专业领域知识
TASKS #为智能体制定工作流程
REQUIRED #限制智能体的行为
# 工作流
智能体每次生成的内容都会存在差异，名为幻觉
是每个大模型都不可避免的问题
这时就需要运用工作流编排特定流程并约束行为，使结果拥有可控性
# 插件
为智能体拓展能力，使智能体可以感受世界
```
