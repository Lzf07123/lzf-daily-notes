# 了解PVE使用命令控制虚拟机

## Context

了解PVE使用命令控制虚拟机，了解qm命令的一些子命令

---

## Key Takeaway

- 虚拟机生命周期管理：`qm start <VMID>`、`qm stop <VMID>`、`qm shutdown <VMID>`、`qm reboot <VMID>`、`qm reset <VMID>`
- 虚拟机查询命令：`qm list`、`qm config <VMID>`
- 虚拟机配置设定命令：`qm set <VMID> <option>`
