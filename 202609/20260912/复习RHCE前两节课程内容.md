## Key Takeaway

- pwd 查看当前工作目录
- ls 查看目录下的内容
- whatis command 查看命令的效果
- command --help 获取命令帮助
- man command 获取命令帮助
- cd 切换工作目录
- touch 新建文件
- mkdir 新建目录
- mv 移动文件/目录或重命名文件/目录
- cp 复制文件或目录
- rm 删除文件
- useradd 添加用户
- usermod 更新用户信息
- userdel 删除用户
- passwd 更新用户密码与用户信息
- groupadd 添加组
- groupmod 更新组信息
- groupdel 删除组
- gpasswd 更新组密码与组信息
- groupmems 管理员管理组命令
