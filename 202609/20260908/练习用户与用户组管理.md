# 练习用户与用户组管理

## Context

练习用户与用户组管理，为个人项目建立运行用户，项目间用户互相独立，需要对用户与用户组进行管理

---

## Key Takeaway

- useradd 新增用户
- usermod 修改用户信息
- chage 设定用户密码轮转策略
- groupmems 将用户加入组

---

## Pratice

- `useradd -d /opt/limedia -c 'Li-Media运行用户' limedia`创建limedia用户并设置说明与主目录
- `groupmems -g docker -a limedia`将用户limedia加入docker组使其可以使用docker命令
